# Lucky Founders Club

Landing Page für den Lucky Founders Club – Next.js mit shadcn/ui.

## Setup

```bash
git clone https://github.com/baetter/luckyfoundersclub.git
cd luckyfoundersclub
npm install
```

## Entwicklung

Dev-Server starten:

```bash
npm run dev
```

Dann [http://localhost:3000](http://localhost:3000) im Browser öffnen.

Die Seite baut auf [Next.js](https://nextjs.org) und [shadcn/ui](https://ui.shadcn.com).
